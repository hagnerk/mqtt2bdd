## Story

**As a** developer,
**I want** to establish a connection to the MQTT broker using configuration from environment variables,
**so that** I can subscribe to topics and receive messages.

9. Manual test: Run application with `docker-compose up`, verify logs show successful MQTT connection to `mqtt2bdd-dev-mosquitto` container

11. All code passes `go fmt`, `go vet`, and `staticcheck`

**Key Paho client options:**
```go
opts := mqtt.NewClientOptions()
opts.AddBroker(fmt.Sprintf("tcp://%s:%d", cfg.MQTTBroker, cfg.MQTTPort))
opts.SetClientID("mqtt2bdd")
// Optional authentication — only set if credentials are configured
if cfg.MQTTUsername != "" {
    opts.SetUsername(cfg.MQTTUsername)
    opts.SetPassword(cfg.MQTTPassword)
}
opts.SetAutoReconnect(false)  // Manual reconnection logic is story 2.2
opts.SetConnectionLostHandler(func(_ mqtt.Client, err error) {
    l.Error("MQTT connection lost", "error", err)
})
```

[Source: docs/architecture/components.md#component-mqtt-client]

**Connect method — token wait with context:**
```go
func (c *Client) Connect(ctx context.Context) error {
    brokerURL := fmt.Sprintf("tcp://%s:%d", c.cfg.MQTTBroker, c.cfg.MQTTPort)
    c.logger.Info("connecting to MQTT broker", "broker", brokerURL)
    token := c.pahoClient.Connect()
    if !token.WaitWithContext(ctx) {
        return fmt.Errorf("MQTT connect timed out waiting for broker %s", brokerURL)
    }
    if err := token.Error(); err != nil {
        c.logger.Error("MQTT connection failed", "broker", brokerURL, "error", err)
        return fmt.Errorf("failed to connect to MQTT broker %s: %w", brokerURL, err)
    }
    c.logger.Info("MQTT connected", "broker", brokerURL)
    return nil
}
```

func (c *Client) Disconnect() {

  - **Why**: `Connect()` already logs the full error with broker context at the point of failure. The duplicate log in `main.go` added noise with less context (missing `broker` field).

- **File**: `internal/mqtt/types.go`
  - **Change**: Removed `// It is used by the Subscribe method (story 1.6).` from `MessageHandler` godoc.
  - **Why**: Internal story tracking references don't belong in public API documentation — they're meaningless to consumers and will become stale.
