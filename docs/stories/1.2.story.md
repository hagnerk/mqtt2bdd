### Package Placeholder File Format

Each placeholder file follows the Go file organization standard (coding-standards.md):

```go
// Package config handles loading and validating application configuration
// from environment variables following twelve-factor app principles.
package config
```

- Package comment (godoc-compliant) on the first file of the package
- Package name = last element of import path: `config`, `logger`, `mqtt`, `database`
- No other content — implementation comes in Stories 1.3–1.7

[Source: architecture/coding-standards.md#comments-and-documentation]

### Coding Standards (Non-Negotiables)

| Tool | Command | Requirement |
|------|---------|-------------|
| `go fmt` | `go fmt ./...` | Zero output (already formatted) |
| `go vet` | `go vet ./...` | Zero warnings |
| `staticcheck` | `staticcheck ./...` | Zero warnings |

- Package names: lowercase single word, no underscores (`config`, `mqtt`, `database`, `logger`)
- File organization: package declaration + package comment, then imports, then code
- No magic numbers, no hardcoded credentials, all errors checked

[Source: architecture/coding-standards.md#tooling-enforcement]
