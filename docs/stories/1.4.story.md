# Story 1.4: Implement Structured Logging Package

## Status

Done

## Story

**As a** developer,
**I want** structured logging with configurable levels (INFO, DEBUG, ERROR),
**so that** I can troubleshoot issues effectively in development and production.

## Acceptance Criteria

1. `internal/logger/logger.go` wraps Go's `log/slog` package providing `Info()`, `Debug()`, `Error()` methods
2. `InitLogger(level string) *slog.Logger` function initializes slog with Text handler writing to stdout
3. Log level configurable via parameter: "DEBUG", "INFO", "ERROR" (case-insensitive)
4. Invalid log level defaults to INFO with warning message logged
5. Logger provides context-aware methods accepting key-value pairs: `l.Info("message", "key1", value1, "key2", value2)`
6. `main.go` updated to initialize logger with `cfg.LogLevel` after configuration loads
7. Logger outputs to stdout in Text format (human-readable) with fields: timestamp, level, message, and any additional context
8. Unit tests validate logger initialization with different levels and level filtering behavior
9. `main.go` declares package-level `var Version = "dev"` and logs application startup at INFO level with version
10. All code passes `go fmt`, `go vet`, and `staticcheck`

> **Note on AC2/AC7 (PRD deviation):** The PRD specifies a JSON handler. The architecture component spec (`components.md`) specifies a **Text handler** for human-readable output, which is consistent with the example log output shown. This story implements the Text handler as per the architecture. A switch to JSON output may be revisited in Story 2.5 (Enhance Structured Logging).

### Logger Component — Authoritative Specification

```go
func InitLogger(level string) *slog.Logger {
    var logLevel slog.Level
    switch strings.ToUpper(level) {
    case "DEBUG":
        logLevel = slog.LevelDebug
    case "INFO":
        logLevel = slog.LevelInfo
    case "ERROR":
        logLevel = slog.LevelError
    default:
        logLevel = slog.LevelInfo
    }

    handler := slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
        Level: logLevel,
    })

    return slog.New(handler)
}
```

The architecture also specifies `NewLogger(level string, w io.Writer) *slog.Logger` as the underlying function (required for testability). `InitLogger` delegates to it with `os.Stdout`.

### Naming Conflict: `logger` Package vs Variable

`main.go` imports `internal/logger` as package name `logger`. Do NOT name the variable `logger` — it shadows the package. Use a short variable name:

```go
import (
    "log"

    "github.com/hagnerk/mqtt2bdd/internal/config"
    "github.com/hagnerk/mqtt2bdd/internal/logger"
)

var Version = "dev"

func main() {
    cfg, err := config.LoadConfig()
    if err != nil {
        log.Fatalf("configuration error: %v", err)
    }
    l := logger.InitLogger(cfg.LogLevel)
    l.Info("MQTT2BDD starting", "version", Version)
}
```

The stdlib `log` package (for pre-logger fatal) and the internal `logger` package coexist without conflict. `l` is a conventional short name for a logger variable in narrow scopes.

## Testing

**Test file:** `internal/logger/logger_test.go`

**Package:** `package logger_test` (black-box — tests the exported API)

**Pattern:** Table-driven tests using `t.Run()`. No third-party libraries — only stdlib `testing`, `bytes`, `strings`.

**Key principle:** Test level filtering behaviour (which messages appear), not output format. The test strategy explicitly states "Log output format — log messages are operational, not contractual; they will change over time."

Use `NewLogger(level, &buf)` to capture output into a `bytes.Buffer` for assertions:

```go
func TestNewLogger(t *testing.T) {
    tests := []struct {
        name       string
        level      string
        debugShown bool
        infoShown  bool
    }{
        {"debug level", "DEBUG", true, true},
        {"info level", "INFO", false, true},
        {"error level", "ERROR", false, false},
        {"case insensitive", "debug", true, true},
        {"invalid defaults to info", "INVALID", false, true},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            var buf bytes.Buffer
            l := logger.NewLogger(tt.level, &buf)
            if l == nil {
                t.Fatal("NewLogger() returned nil")
            }

            l.Debug("debug-probe")
            l.Info("info-probe")

            gotDebug := strings.Contains(buf.String(), "debug-probe")
            gotInfo := strings.Contains(buf.String(), "info-probe")

            if gotDebug != tt.debugShown {
                t.Errorf("debug visible=%v, want %v", gotDebug, tt.debugShown)
            }
            if gotInfo != tt.infoShown {
                t.Errorf("info visible=%v, want %v", gotInfo, tt.infoShown)
            }
        })
    }
}
```
